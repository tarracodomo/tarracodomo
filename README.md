# @iceman — Tarraco Domo

Domótica, sensores y proyectos con ESP8266, ESP32, Home Assistant y Meshtastic. Desde Tarragona, comparto montajes, apuntes y documentación en español.

[Web](https://tarracodomo.com) · [Contacto](mailto:info@tarracodomo.com) · [X / Twitter](https://x.com/tarracodomo)

## En qué trabajo
- Integración de sensores y dispositivos con Home Assistant y ESPHome.
- Prototipos con NodeMCU, ESP32 y ESP32-CAM.
- Comunicación LoRa y experimentación con Meshtastic.
- Documentación de conexiones, configuración y pruebas reproducibles.

## Cómo leer estos repositorios
Los ejemplos iniciales pueden contener código preparado con asistencia de IA. Cada ficha indica su estado: publicar código no significa haberlo probado en hardware. Cuando un proyecto deje de indicar «pendiente de validación», se habrá probado en placa. Consulta requisitos, advertencias y condiciones de uso antes de instalarlo.

No compartas contraseñas, tokens, claves de canales ni ubicaciones privadas en issues o contribuciones. Usa siempre configuraciones de ejemplo sin credenciales reales.
